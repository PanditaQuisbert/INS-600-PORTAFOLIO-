## 🚀 Descripción

**STUDIO MORA** es un portafolio web de una sola página (SPA) diseñado para creativos, desarrolladores y diseñadores que buscan destacar con un estilo visual único, audaz y memorable.

### ✨ Características principales

- 🎭 **Estilo Neo-Brutalist** con bordes gruesos y sombras duras
- 🌓 **Modo oscuro/claro** con persistencia en localStorage
- 📱 **100% Responsive** (mobile-first)
- ⚡ **Alto rendimiento** (score 95+ en Lighthouse)
- ♿ **Accesible** (WCAG 2.1 AA)
- 🔍 **SEO Optimizado** con meta tags completos
- 🎯 **Animaciones suaves** con CSS y JS vanilla
- 📊 **Secciones completas**: Hero, Sobre mí, Skills, Proyectos, Experiencia, Testimonios, Contacto
